# 掼蛋规则基线（江苏 / 淮安主流规则）

参考：[联众掼蛋 游戏规则](https://www.ourgame.com/game/game-intro-new/df/sc/h2g/egglaying_002.html)

本文件是 `src/core` 的规则契约。凡有地区差异处，一律做成 `rules.ts` 中的配置项。

---

## 1. 基础

- 2 副标准扑克（含大小王），共 **108 张**；4 人各 **27 张**。
- 座位 0/1/2/3，逆时针出牌；**0 与 2 为队友，1 与 3 为队友**。
- 出完手牌的先后：**头游（上游）→ 二游 → 三游 → 末游（下游）**。
- 队友分别拿到头游 + 二游，称为**双下**（把对方两人"双下"）。

## 2. 级牌与逢人配

- **级牌**：当前所打的级（初始打 2，即 2 为级牌）。
- 大小：`大王 > 小王 > 级牌 > A > K > Q > J > 10 > ... > 3 > 2`。
  - 单张、对子、三同张、炸弹的比点均采用该序（**级牌当 15 用**）。
  - 打 A 时，A 本身即级牌。
- **逢人配**：两张**红桃级牌**，可替代**除大小王以外**的任意一张牌，用于组成任意牌型（含同花顺、炸弹）。

## 3. 牌型（10 种）

| 牌型 | 结构 | 说明 |
|---|---|---|
| 单张 | 1 张 | 不分花色 |
| 对子 | 2 张同点 | |
| 三同张 | 3 张同点 | 三不带 |
| 三带二 | 3 张同点 + 1 对 | 只比三同张大小 |
| 顺子 | 5 张连续单牌 | 花色不限；A 可作 1 或 14（A2345 / 10JQKA），**不可 JQKA2** |
| 三连对（木板） | 3 个连续对子 | 如 334455；A 可作 1（AA2233） |
| 三连同张（钢板） | 2 个连续三同张 | 如 333444；A 可作 1（AAA222） |
| 炸弹 | 4–10 张同点 | 张数越多越大 |
| 同花顺 | 5 张同花色顺子 | 属炸弹，序位于 5 张炸与 6 张炸之间 |
| 四大天王 | 2 小王 + 2 大王 | 最大，可压一切 |

## 4. 压制关系

```
四大天王  >  六张及以上炸弹  >  同花顺  >  五张及以下炸弹  >  普通牌型
```

- 普通牌型之间：**必须类型相同、张数相同**才能比较，比主牌点数。
  - 顺子比最大牌（A2345 记 5，10JQKA 记 14），**顺子中级牌按自然点数参与**。
  - 三带二只比三同张。
  - 连对/钢板比最大的那一组。
- 炸弹之间：张数不同比张数（同花顺视作 5.5 张），张数相同比点数。
- 同点同型不算"更大"，不能压（必须严格大于）。
- **一手多解取最强**：同一组牌可能有多种解释（典型：逢人配参与的顺子）。
  例如 `红桃7 红桃8 红桃(配) 红桃10 红桃J` 既可读作顺子、也可读作同花顺。
  由于用的是**完全相同的几张牌**，强解释严格不劣于弱解释，因此一律取最强的那个 ——
  否则会出现"打出去的是同花顺、却按顺子结算，被一张四张炸压掉"的事故。

## 5. 出牌流程

1. 首出者出牌，其余人按逆时针依次跟牌：**出更大的同型牌 / 出炸弹 / 过**。
2. 连续 3 家"过"后，最后出牌者获得新一轮出牌权。
3. 首出者**不能过**（手上还有牌时必须出牌）。
4. **接风（对门借风）**：某玩家打出最后一手牌走掉后，其余三家均不要，则由其**搭档**接风出牌；搭档若也走完，则由其下家第一个未走完的玩家接风。
5. 一局在**第 3 人走完**时结束，剩下一人为末游。
6. **双下提前收局**：若头游与二游是同一队（对方双下），升级已成定局（+3），
   本局立即结束，不再继续打三游/末游（这两名的先后不影响任何结算）。
   可由 `endEarlyOnDoubleDown` 关闭以打满四人名次。

## 6. 升级

只有**头游一方**升级，按头游队友的名次：

| 头游队友名次 | 升级 |
|---|---|
| 二游（双下） | +3 |
| 三游 | +2 |
| 末游 | +1 |

级序：`2 → 3 → ... → 10 → J → Q → K → A → 过A`。升级**不能跳过 A**（封顶到 A）。

## 7. 过 A（终局）

- 从 2 打起，打过 A 即赢得本大轮（比赛结束）。
- **打 A 局**中，需满足「本队一人头游，另一人**不是末游**」（即头游+二游 或 头游+三游）才算过 A；头游+末游不算，需继续打 A。
- **三次不过 A**：按配置处理（`降回 2 重打` / `继续打 A`），默认降回 2。

## 8. 进贡 / 还贡 / 抗贡

上一局结束后进入本局的进贡阶段：

- **单下**（输方名次为二游+末游，或头游队友为末游时的三游）：**末游（或输方名次最低者）向头游进贡一张**，然后**由进贡者先出牌**。
- **双下**（输方为三游+末游）：输方两人都要进贡：
  - 两人各交出**除红桃级牌外的最大一张牌**；
  - 两张贡牌中**较大的给头游**，较小的给二游（联众规则：头游默认拿大牌）；
  - 还贡时对应还给各自的进贡者；
  - **由贡出大牌者先出牌**。
- **还贡**：收贡者须还给进贡者一张**点数 ≤ 10** 的牌（不含大小王、不含红桃级牌）。
- **抗贡**：需要进贡的一方手中**合计有两张大王**即可抗贡（单下时即该玩家持有两张大王）。抗贡后不进贡、不还贡，**由头游先出牌**。
- **进贡牌不能是红桃级牌（逢人配）**，取手中除此之外的最大牌。

## 9. 首局

第一局无进贡，由随机一家（或玩家指定）先出牌。

## 附：配置项清单（`rules.ts`）

| 配置 | 默认 | 说明 |
|---|---|---|
| `tributeEnabled` | true | 是否启用进贡/还贡 |
| `tributeReturnMaxRank` | 10 | 还贡牌点数上限 |
| `bombMaxSize` | 10 | 炸弹最大张数 |
| `straightFlushBetween5And6` | true | 同花顺算 5.5 张炸弹 |
| `allowAceLowInTubePlate` | true | 连对/钢板中 A 可作 1 |
| `passACondition` | `'notLast'` | 过 A 需队友非末游 |
| `aRetryLimit` | 3 | 三次不过 A |
| `aRetryPolicy` | `'reset'` | 降回 2 / `'keep'` 继续打 A |
| `levelCapAtA` | true | 升级不跳过 A |
| `endEarlyOnDoubleDown` | true | 双下时立即收局，不再打三游/末游 |
| `doubleTributeBigToHead` | true | 双贡大牌给头游 |
